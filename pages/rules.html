Rules & Disclaimers

No Money. No Wagering. Educational Demo Only. This project uses virtual coins and mock data. It must not be used for gambling or real-money wagering.
  • You start with 1000 virtual coins stored in your browser (LocalStorage).
  • Place picks on upcoming events before they start. You can cancel before start to refund coins.
  • Results are simulated for demo purposes. Payouts add coins back to your local balance.
  • No accounts, no servers, no prizes, no withdrawals—this is a static front‑end learning example.
